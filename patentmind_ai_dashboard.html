LLM novelty assessment
The uploaded patent describes transformer pruning combining dynamic attention sparsity with input-adaptive masking. Semantic search retrieved US11,847,203 (Google, 2023) at 94% similarity — that patent covers sparse attention but applies a static sparsity schedule, not dynamic input-conditioned masking. US11,704,589 (Microsoft, 2023) at 88% uses RL to select heads for pruning but does not address per-token attention sparsity at inference time. The LangGraph traversal confirmed inventor Zhang, Wei co-invented US11,847,203, establishing direct prior art lineage — this is structural evidence not detectable via semantic similarity alone. Based on both branches, the primary novel element appears to be real-time dynamic masking conditioned on input complexity — not present in any retrieved patent. Recommended for legal review before filing.
